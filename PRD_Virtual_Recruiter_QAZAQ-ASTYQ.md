# Виртуальный рекрутер
## Product Requirements Document (PRD)

**Компания:** QAZAQ-ASTYQ GROUP  
**Версия:** 1.0  
**Дата:** 29 мая 2025  
**Статус:** На согласовании  
**Для кого:** HR-специалисты, HR Generalist, Директор по персоналу, Руководители подразделений

---

## 1. Цель проекта

Создать веб-сервис «Виртуальный рекрутер», который автоматически анализирует описание вакансии и находит наиболее подходящих кандидатов на hh.kz.

**Главная задача** — сократить время поиска кандидатов на 70–80%. Вместо ручного просмотра сотен резюме HR-специалист получает готовый рейтинг с оценками и рекомендациями.

---

## 2. Для кого создаётся сервис

Сервис предназначен для сотрудников без технических знаний:

- HR-специалисты
- HR Generalist
- Директор по развитию персонала и корпоративной культуры
- Руководители подразделений

---

## 3. Как работает сервис — шаг за шагом

### Шаг 1. Загрузка вакансии

HR-специалист вставляет текст вакансии или загружает файл в формате Word или PDF. Сервис автоматически извлекает из текста:

- Название должности
- Требуемый опыт работы
- Образование
- Обязательные навыки
- Желательные навыки
- Местоположение
- Зарплатную вилку

### Шаг 2. AI-анализ вакансии

Искусственный интеллект разбирает вакансию и показывает:

- Ключевые компетенции
- Hard skills (технические навыки)
- Soft skills (личные качества)
- Обязательные и желательные требования

HR-специалист проверяет результат и нажимает **«Начать поиск»**.

### Шаг 3. Поиск кандидатов на hh.kz

Сервис заходит на hh.kz под корпоративным аккаунтом компании и автоматически просматривает резюме. Поиск ведётся по должности, навыкам, региону, опыту и уровню зарплаты.

Сервис также понимает синонимы. Например, для «Главного технолога маслозавода» автоматически ищет:

| Указано в вакансии | Сервис также ищет |
|---|---|
| Главный технолог маслозавода | Chief Technologist |
| | Process Engineer |
| | Production Technologist |
| | Refinery Technologist |

### Шаг 4. Оценка и рейтинг кандидатов

Для каждого кандидата рассчитывается **Match Score** — показатель соответствия от 0 до 100%:

| Критерий оценки | Вес |
|---|---|
| Соответствие опыту работы | 35% |
| Соответствие навыкам | 30% |
| Соответствие отрасли | 20% |
| Соответствие образованию | 15% |

**Пример результата:**

> **Иван Иванов — 92%**
> - ✅ 8 лет опыта
> - ✅ Опыт на производстве
> - ✅ Управление командой 50+ человек
> - ⚠️ Нет опыта работы с ERP-системами

### Шаг 5. Карточка кандидата

По каждому кандидату сервис показывает:

- ФИО, должность, город
- Опыт работы и зарплатные ожидания
- Навыки и ссылку на резюме

AI формирует два блока:
- **«Почему кандидат подходит»**
- **«Какие есть риски»**

### Шаг 6. Сравнение и рекомендации

Таблица сравнения ТОП-20 кандидатов по всем критериям. Раздел **«Кого рекомендую пригласить»** делит кандидатов на три группы:

- 🟢 Пригласить немедленно
- 🟡 Рассмотреть дополнительно
- 🔴 Низкий приоритет

### Шаг 7. AI-интервью

После выбора кандидата система автоматически генерирует вопросы для собеседования:

- Вопросы по компетенциям
- Технические вопросы
- Вопросы по ценностям компании

Формируется AI-отчёт для руководителя с обоснованием рекомендации.

### Шаг 8. Экспорт

Результаты поиска выгружаются в форматах:

- PDF
- Excel
- Word

## 4. Интеграция с hh.kz

Так как официальный API hh.kz недоступен, сервис использует **авторизованный браузерный сеанс**. Это означает: сервис заходит на hh.kz под корпоративным аккаунтом компании так же, как это делает HR-специалист вручную, — только автоматически.

### Как хранятся данные аккаунта

Логин и пароль от hh.kz хранятся в **зашифрованном защищённом файле на сервере**. Ни один сотрудник не видит пароль в интерфейсе сервиса. Данные вводятся один раз через специальную форму настроек.

### Ограничения

- Сервис делает паузы между просмотрами резюме (3–8 секунд), чтобы не нарушать правила hh.kz
- Рекомендуемый лимит: не более 200 резюме в день
- Если аккаунт hh.kz платный — сервис видит контакты кандидатов. Если бесплатный — только имя, опыт и навыки

## 5. Из чего состоит сервис

| Часть | Технология | Что делает |
|---|---|---|
| Интерфейс (то, что видит пользователь) | React + Next.js | Страницы, кнопки, карточки кандидатов |
| Серверная часть (невидимая) | Python + FastAPI | Логика поиска, AI-анализ, обработка данных |
| База данных | PostgreSQL + Redis | Хранение кандидатов, истории поисков, сессий |
| AI-движок | Claude API | Анализ вакансий, скоринг резюме, рекомендации |
| Поиск на hh.kz | Playwright | Автоматический просмотр резюме |

---

## 8. Безопасность данных

- Логин и пароль от hh.kz хранятся в зашифрованном виде — никто из сотрудников не видит их в системе
- Данные кандидатов хранятся только на сервере компании
- Доступ к сервису — только по корпоративному логину и паролю
- История поисков доступна только авторизованным пользователям
- Все соединения защищены (HTTPS)
